## Coordinator Counter Demo

This repository includes a very small, dependency-free browser demo located in the `demo/` directory.

### Usage

1. Open `demo/index.html` in any web browser.
2. The page displays an integer counter which starts at 0.
3. You can interact with the counter using the on-screen buttons or keyboard shortcuts.
4. The counter value will persist even if you reload the page. The counter will never go below 0.

### Keyboard Shortcuts

- `+` : Increment the counter.
- `-` : Decrement the counter.
- `r` : Reset the counter to 0.
